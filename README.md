# Student Record Management System

A modular CRUD management console application built with Python and MySQL.

## Features
- Add student records with primary key validation
- View all students in formatted tabular output
- Search students by roll number
- Update student credentials
- Delete student records with confirmation
- Database-level aggregation (average marks)
- Sorting records by marks in descending order

## Tech Stack
- **Language:** Python 3.x
- **Database:** MySQL
- **Connector:** `mysql-connector-python`
